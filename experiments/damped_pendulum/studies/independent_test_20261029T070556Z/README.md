重复审计的范围和结果

- 对照两种阻尼的旧训练/验证轨迹前 81 帧，以及此前已查看过的旧测试轨迹全部 325 帧；检查这些范围内的所有连续窗口，比实际训练窗口范围更保守。
- 新初始物理状态与旧初始状态的精确重复为 0；完整物理状态与动作轨迹精确重复为 0；新样本内部初始物理状态重复为 0。
- 低分辨率图像存在量化碰撞：合并两个阻尼条件及两个模型的检查后，19 个配对编号的初始训练长度片段与旧数据精确重复。这 19 个编号从两组正式测试分区同步排除，原数据仍保留。
- 正式分区对所检查的 LeWM 13 帧、LeHami 14 帧图像加有效动作片段，剩余精确重复为 0。严格诊断分区的初始 4/5 帧图像精确重复也为 0。
- 这不保证没有近似样本，也不保证每个未来时刻的图像窗口都从未出现过。初始视觉上下文重复不自动等于真实值被在线输入模型。
- 去重改变了分布：初始能量中位数从 8.09 J 变为正式分区的 8.86 J，严格诊断分区为 13.71 J。因此应同时报告全部新样本与去重分区，分别报告无外力/受控结果；严格分区只有 16 对，不能单独代表整体性能。

后续评测的固定约束

1. 从 frozen 目录读取已归档检查点和原始读出器，并在评测前后验证哈希；不使用新数据计算归一化量、拟合读出器或选择超参数。
2. 使用 eval 模式并关闭参数梯度，保留哈密顿流计算内部状态导数所需的机制。模型输入仅包含初始 5 帧和合法的外生控制序列；真值只用于评分。
3. 两个模型都从原始第 4 帧开始自主递推，不重新编码后续真实帧。LeHami 内部取初始历史的第 1..4 帧，LeWM 使用第 0..4 帧。
4. 两个固定读出器、三个训练种子、两种动作模式和原有预测时长均保留，不能按新测试成绩挑选结果。
5. 不要直接调用原 dpbench.evaluate.evaluate：它要求数据哈希等于训练数据，而且会重新拟合读出器。下一步需要独立的只加载冻结读出器的评测入口，分别校验训练来源与新测试集的哈希；不能通过改写检查点里的训练数据哈希来绕过检查。
6. 如果以后依据本测试集结果调参，它即成为开发数据；最终结论应再使用未查看的新测试集。

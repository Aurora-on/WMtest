# 位置与速度相关耗散世界模型的训练方案

日期：2026-10-29。当前交付为代码与非训练检查，尚未启动新模型训练，也未提交服务器作业。本文沿用完整推导报告当前的 JEPA 主线；不增加图像解码器，不改变现有 LeHami、LeWM 的模型和训练配方。

## 1 训练目标与现有数据边界

新增模型需要从初始五帧 RGB、过去动作和时间间隔构造相空间状态，在给定未来动作下自主预测。默认耗散力为

\[
Q_{\rm diss}(q,v)=-D_\theta(q,v)v,\qquad D_\theta=L_\theta L_\theta^T.
\]

这保证所学潜储能的耗散功率非负。耗散大小和位置、速度依赖从预测误差中学习；不会由内部能量等式自动识别。

直接使用现有 `data/basic/pendulum_b0p0.h5` 与 `pendulum_b0p2.h5`，两者分别训练，不向网络提供阻尼组标签。每组 512 条轨迹，384/64/64 条 train/val/test，64×64 RGB，帧间隔 0.1 秒。训练、验证和后续读出校准仍限于每条轨迹前 81 帧，即原始轨迹的 0–8 秒。

现有数据的真实阻尼分别为常数 0 和 0.2。因此可以检验非线性耗散模型能否拟合这些特例，不能单独证明模型学会了真实的状态相关阻尼。完整推导中的位置与速度相关振子应作为后续新增数据实验；本轮没有改写或重新生成正式数据。

训练加载器只返回 `pixels`、`action`、`dt_frame`。状态、能量、质量、阻尼、参考功和耗散都不进入模型输入或损失。动作模式仅从允许前缀的动作序列推导，用于采样分层。预检检查 episode/group ID 分割，不将其误称为图像内容去重；已有独立测试集及去重审计仍需保留。

## 2 对原训练思路的具体改进

| 问题 | 当前实现 | 仍需验证的边界 |
|---|---|---|
| 只有能量等式，没有学习真实阻尼的信号 | 用自主多步预测误差训练 D；内部收支只记录，不作为零值恒等损失 | 小预测误差不保证 D 唯一或物理标定 |
| 潜空间同时移动，过多分阶段策略难以解释 | 全程联合训练同一目标，仅渐进增加预测长度；不做纯 SIGReg 预热或中途冻结 | 最优阶段长度须由预注册验证协议检验 |
| 预测静止也可能满足耗散约束 | 保留预测损失，增加帧间位移误差；记录 copy-last 基线、表示尺度与运动幅度 | 位移目标也是所学表征，仍需独立物理评测 |
| 时间差分与积分器时钟不统一 | 因果二次拟合使用实际 dt，积分子步和输入功也使用秒 | M=I 仍只是潜坐标模型选择 |
| BatchNorm 可能将未来帧统计带入初始化 | 单帧卷积编码器使用 GroupNorm，无跨图像统计 | 新编码器与旧基线并非完全相同架构 |
| 短预测与长预测目标难度不同，训练损失不可直接比较 | 固定验证窗口及 8/32 步验证时域，不随 curriculum 变化 | 潜空间选模分数只用于本模型训练内部 |
| 求解器误差被当成物理性质 | 记录动力学残差、链式缺陷、输入功、耗散和实际能量变化；失败直接终止 | 数值收支正确仍不保证轨迹正确 |
| 无法区分结构收益与额外计算 | 同一 H/D/B 支持离散梯度与 RK4；同一配置支持不同耗散输入 | 正式比较必须报告实际计算成本 |

## 3 可实现的模型与初始化

编码器逐帧输出 q=e_φ(o)，默认 q 维度为 2。卷积宽度为 32，使用 GroupNorm，保留空间特征后投影；没有外观码、时间码或绕过动力学的递归隐藏状态。此 q 是位置样潜变量，并非预先标定的真实摆角。

在五个历史时刻上，以最后时刻为零、历史总时长为尺度，将每个潜坐标拟合为二次多项式。其末端导数给出 v_fit。初始化为

\[
q_0=e_\phi(o_0),\qquad
p_0=v_0=v_{\rm fit}+s_v\tanh r_\eta(q_{-4:0},u_{-4:-1},h_{-4:-1}).
\]

默认 s_v=1，修正网络最后一层零初始化，并有小幅修正正则。它补偿因果差分偏差与历史动作影响；未来帧和未来动作不进入初始状态。q_0 保持为最后一帧的编码，不用多项式拟合值替换。

潜动力学取 M=I、H=||p||²/2+V_θ(q)。V 使用平滑网络与 softplus 保持下有界；D 接收 q、v 并输出下三角因子 L，再取 LLᵀ；B(q)u 是显式动作端口。初始化使阻尼因子非零，避免全零因子的梯度退化。

q 维度为 2 是降低隐式求解成本的初始选择，不能由摆的自由度直接推出它一定合适；周期角度的拓扑、潜坐标度量和 M=I 的适配性都可能限制表示。应通过同协议的 q_dim=2/4/8 消融区分表示瓶颈与耗散机制，不能把这一坐标选择解释为真实机械能的保证。

视觉部分为 FP32，动力学为 FP64。首版支持 CPU/CUDA，明确拒绝 MPS；未验证的精度或设备不会自动回退。默认每个 0.1 秒帧间隔分为两个 0.05 秒子步，使用同一零阶保持动作。离散梯度分支按实际执行的有限 Newton 迭代反传，默认每子步最多 6 次更新，不用收敛根公式替代未收敛算法的梯度。

## 4 训练损失与课程长度

记从初始状态自主推演得到的预测为 q̂_j，未来图像的编码目标为 q_j^enc，q̂_0=q_0^enc。所有未来目标只用于损失，绝不重新初始化推演状态。

\[
\mathcal L_{\rm pred}=\frac1K\sum_{j=1}^K\|\hat q_j-q_j^{\rm enc}\|^2,
\]
\[
\mathcal L_{\Delta}=\frac1K\sum_{j=1}^K
\| (\hat q_j-\hat q_{j-1})-(q_j^{\rm enc}-q_{j-1}^{\rm enc})\|^2,
\]
\[
\mathcal L=\mathcal L_{\rm pred}
+1.0\,\mathcal L_{\Delta}
+0.25\,\mathcal L_{\rm SIGReg}
+10^{-3}\|v_0-v_{\rm fit}\|^2.
\]

实现对 batch、时间和坐标取均值。位移项不除以 dt，因此不会因 dt=0.1 将其放大 100 倍；它不是物理速度标签，也不将中心差分强行当成潜动量。SIGReg 直接加载经 hash 验证的固定 LeWM 源码，作用于图像编码 q，不对 p 强制高斯化。默认 17 个积分节点、256 个随机投影；随机投影数可配置，这不是对原基线 1024 投影配方的原样复现。

预测分支和目标分支都向同一编码器反传，保留 SIGReg 防塌缩；没有额外 EMA 网络。没有阻尼标签损失、能量单调惩罚或内部收支恒等损失。受控系统允许输入功使能量上升。

默认优化配置是尚未经过训练调优的起点：

| 优化步 | 自主预测长度 | 物理预测时长 |
|---|---:|---:|
| 1–1,000 | 4 帧间隔 | 0.4 秒 |
| 1,001–4,000 | 8 帧间隔 | 0.8 秒 |
| 4,001–10,000 | 16 帧间隔 | 1.6 秒 |
| 10,001–20,000 | 32 帧间隔 | 3.2 秒 |

始终联合更新，不在阶段间更换损失定义。AdamW 的编码器学习率为 2e-5，动力学与速度初始化器为 1e-4；500 步线性预热后余弦下降至初始值的 10%，weight decay=1e-4，梯度范数裁剪为 1，batch=32。这些数值不代表已验证的最佳超参数；20,000 步也不是收敛承诺或服务器耗时估计。

最大窗口为 5+32=37 帧，每个阻尼组有 17,280 个训练窗口和 2,880 个验证窗口。按自由/受控动作模式及有效起点的早中晚区间分层，层内均匀采 episode 再采起点。短 curriculum 阶段从同一最大窗口截取，因此固定了起点分布，并未使用全部可能的短窗口。采样由 seed 和全局优化步确定，恢复时不依赖 DataLoader 的隐含游标。

## 5 验证 选模与恢复

验证固定使用 256 个不重复窗口，覆盖动作模式和起点区间；同时评价 8 步与 32 步，即 0.8 秒与 3.2 秒。验证始终在前 81 帧内。原协议的 4/8/16/32 秒长时测试仍是独立最终评测，不能把 32 步误写成 32 秒。

每个模式、起点区间和预测时域先汇总目标表征矩，再以目标方差归一化预测 MSE；各组等权形成选模分数。使用汇总矩可避免尾部小 batch 改变归一化和表示门限。记录同一目标空间的 copy-last MSE 与比值，帮助识别没有学会运动的模型。

进入 best checkpoint 还要求各验证组的最小坐标标准差至少 0.1、目标帧间位移 RMS 至少 0.001。这些是可配置的表示有效性筛查，不能证明物理正确，也可能拒绝本来就低运动的验证组；不通过时保留 last 和明确状态，不把它自动解释为求解失败。SIGReg 不用于 checkpoint 排名，避免其 batch 大小依赖混入选模分数。

验证会恢复调用前的随机数状态，不改变后续训练的 SIGReg 随机投影。原子保存 last/best、优化器状态、随机数状态、全局步、固定验证索引、完整配置、数据 SHA256 与源代码 hash；恢复时核验对应信息。恢复承诺是相同软件和设备环境下的采样与随机状态延续，不是跨平台逐位一致的保证。最佳模型若早于 last，迁移恢复时也应带上对应 best 文件。

求解失败或非有限损失/梯度会明确写入失败状态并终止；不跳过样本，不降级成另一个积分器继续算。日常日志记录训练目标、表示尺度、copy-last 比值、功与耗散、动力学残差、链式缺陷及实际能量收支缺陷。RK4 的求解残差字段不适用，置零不代表其严格满足离散能量等式；其数值收支误差单独记录。

## 6 消融与结果解释

新分支配置支持 `core.damping_mode` 为 `none`、`constant`、`position`、`position_velocity`，以及 `core.integrator` 为 `discrete_gradient`、`rk4`。修改 JSON 时保持其他参数、数据、种子、采样和验证规则一致。

优先比较同一新编码器、初始化器和损失下的 RK4 与离散梯度，再比较耗散输入形式。需要另做固定 K=8 的训练长度对照时，将 curriculum 改为一个覆盖全部步数的 horizon=8 阶段；验证仍可固定为 [8,32]。不要只对新模型增大训练长度，再把优于旧基线的差异归结为耗散结构。

旧 LeWM、LeHami 结果可提供背景参照，但本分支改变了编码器归一化、潜维度、初始化、优化器和课程长度，不能将分数差直接解释为单一方法因素。不同积分器还应比较相同计算预算及步长敏感性，而不只比较相同优化步数。

模型提供原 `rollout_features` 接口，`load_checkpoint` 已支持新模型，可通过 `dpbench.evaluate` 在原数据协议上校准并冻结 ridge/MLP 物理读出。该评测命令包含读出拟合，本轮没有执行。旧 `evaluate_holdout.py` 的完整入口仍绑定已冻结的 47111 基线矩阵；将新模型加入独立测试需另建对应检查点与读出清单，不能直接复用旧矩阵成绩。真实角度、角速度和能量标签只在独立评测链中使用；训练潜分数、模型内部储能收支和真实轨迹误差分开报告。

## 7 代码入口与运行边界

| 文件 | 职责 |
|---|---|
| `dpbench/dissipative_core.py` | H/D/B、离散梯度与 RK4、有限求解和功耗记账 |
| `dpbench/dissipative_model.py` | 单帧 JEPA 编码、因果状态初始化、自主预测与损失 |
| `dpbench/dissipative_data.py` | 数据白名单、前缀边界、分层采样、只读预检 |
| `dpbench/train_dissipative.py` | 课程长度、优化、固定验证、检查点与恢复 |
| `configs/dissipative_jepa.json` | 默认训练配置，可显式覆盖模型选项 |
| `tests/test_dissipative_*.py` | 数值、梯度、信息流、采样和训练入口检查 |

以下命令只预检，不构造优化器，不创建训练输出目录：

```bash
.venv/bin/python -m dpbench.train_dissipative \
  --data data/basic/pendulum_b0p2.h5 \
  --config configs/dissipative_jepa.json
```

后续获准启动时才使用 `--execute`，并明确指定空输出目录与设备。当前没有执行带该开关的命令，没有生成新模型训练权重；也没有运行物理读出拟合。

实际检查结果保存于 `reports/dissipative_code_checks_2026-10-29.json`。单元测试中的 forward/backward 只检查计算图与梯度，不执行参数更新。由于本轮不启动训练，尚无收敛曲线、训练速度、显存预算或模型性能结论。

03 模型、学习目标与几何边界
保守骨架与阻尼适配
A 从图像学习位置表示 q、初始潜速度 / 动量 p 以及势函数 V。潜质量 M=I₂ 是模型假设，不等于已校准的物理质
量。B 在相同骨架上增加正半定阻尼；multi 的 c 由初始历史产生并在 rollout 内固定，仅作用于 D。
H(q,p) = ½ pTp + V(q)
dq/dt = p
dp/dt = −∇V(q) − D(q,p,c)p
D = LLT ≥ 0（半正定）；A 中 D = 0；单工况不使用 c。
连续形式满足 dH/dt = −pTDp ≤ 0。本次 frozen_dg 使用逐层对称割线离散梯度及隐式求解，能量账本含求解残差
功与链式误差，需按有限容差验收。约束对象为内部 H，不自动等于读出机械能 E(θ,ω) 的平衡。B 初始化 D = 
0.01I，避免 L=0 时 LLT 参数化的零梯度。
LeHami 式损失及监督边界
目标 q* 来自未来图像编码，p* 为五点局部二次拟合导数，二者保持可微；额外未来 2 帧只为末端导数提供监督。
p* 不是标注物理角速度。物理角度与角速度不用于世界模型反向传播，只用于独立读出校准和诊断。
L = Lq + Lp + 0.25 LSIGReg + 0.001 Linit
Lq = MSE(q̂, q*)；Lp = MSE(τp̂, τp*)；τ = 0.1 s
SIGReg 作用于目标 [q*, τp*]；Linit 约束初始修正量 δp₀。
B 冻结 encoder / initializer 后，SIGReg 和初始修正正则仍计入标量 loss，但对本阶段可训练的 D / environment
无梯度；其数值仍随 batch 变化。应优先看位置-动量预测损失、运动门槛和物理预测，不以总 loss 跨阶段排名。
非线性读出改善了什么，尚未证明什么
若 q=e(θ) 为弯曲嵌入，则 d²q/dt²=e′(θ)·d²θ/dt²+e″(θ)·ω²。第二项随速度平方改变，是编码几何引起的加速度。固
定单位动能、只依赖 q 的势力未必能充分表示它；单纯增加维数或换成非线性读出均不能自动消除这项兼容性问
题。
kNN 读出可以更准确地将弯曲潜状态映射回 θ、ω，改善显示与物理评测；它没有更改潜动力学。当前轨迹变好
说明整个“潜预测 + 读出”链路更有效，不能据此宣称几何问题已经从结构上解决。

04 评测协议与完整性核查
读出只用训练划分拟合
在 A20k 的 384 个训练组内部，288 组拟合标准化和 kNN，96 组选择邻居数；候选 k={1,5,25,50}，选中 k=5、
等权平均。特征为 K0 因果历史得到的 [q,p]。A20k、B-single、B-multi 使用逐字节一致的同一读出。
真实历史读出诊断（下文记为 teacher）在每个时刻重新观察真实历史；自主预测只在起点初始化。前者衡量视
觉表示与固定读出的适用性，不是未来自主预测，也不是可从总误差中直接相减的独立误差分量。

计算口径
角度 MAE
对 Δθ 使用 atan2(sin Δθ, cos Δθ) 包裹至圆周最短差，再取绝对值平均。主表统计未来第 1-32 帧，
不含锚点。
角速度 RMSE / NRMSE
RMSE 为物理角速度误差的均方根；NRMSE 以拟合训练数据角速度的标准差归一化，并非每个阻
尼各自重新缩放。
持续停止
在约 1 秒的真值动态窗口中，预测速度 RMS 小于真实速度 RMS 的 10% 判为停止。真值动态阈值
为训练速度尺度的 10%；排除真实自然静止。
物理能量误差
E = ½mL²ω² + mgL(1−cosθ)。未来能量 MAE 以真实锚点能量归一化并取逐轨迹中位数；阻尼下能
量下降本身不是错误。

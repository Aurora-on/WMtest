# 文件范围与复现边界

本仓库是从现有工作区复制整理的独立快照。原实验代码、结果和服务器作业均未移动或更改；Git 历史保留目标仓库已有初始提交。

## 已纳入

- 耗散摆的实现、配置、脚本、测试、固定来源的第三方核心代码。
- 分阶段训练、读出与维数实验的计划、审核和冻结源码。
- 四方法比较的12组验证轨迹 NPZ、评测摘要、协议与来源清单。
- 技术报告、图表、GIF 演示和 H-JEPA 诊断证据。
- 相关官方 LeHami 单种子复现的源码、脚本和结果。

## 未纳入

- 原始 HDF5 数据集、模型 checkpoint、readout 权重和虚拟环境。
- 传输压缩包、重复结果导出、冗长训练日志、下载缓存。
- 其他 WM 项目以及论文 PDF。

[snapshot_inventory.json](snapshot_inventory.json) 逐项记录入库文件 SHA256 和排除原因。`tools/verify_snapshot.py` 核对复制文件和新增整理文件；历史训练包的完整性清单仍保留原含义，不因上传到 Git 就自动成为完整训练存档。

历史 `complete.json` 可能引用未纳入的 `readout.npz` 或其他文件。已有轨迹支持重新汇总指标、绘制动图；重新推理或完整验收仍需原数据、checkpoint 和读出文件。仓库不会为缺失文件伪造通过结果。

部分历史脚本包含原机器路径和内部服务器地址，供审计追溯。本仓库保持原有私有可见性；迁移运行应使用可配置 CLI，不能假定原路径存在。

软件测试、字节校验、任务提交、训练结束和物理验收是不同事实。结果索引区分已完成对比、诊断结果和只提交的新重训任务。历史文档的计划或推测不等于验证结论。
